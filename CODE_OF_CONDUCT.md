# Code of Conduct

## Our standards

We are committed to a welcoming, respectful, and technically constructive community. Contributors are expected to:

- Treat others with respect and professionalism.
- Assume good faith while discussing technical decisions.
- Focus criticism on code, behavior, and evidence rather than people.
- Accept documented corrections and differing technical opinions.
- Protect private information and respect project licenses.

Unacceptable behavior includes harassment, discrimination, threats, personal attacks, doxxing, deliberate disruption, and sharing private or confidential material without permission.

## Enforcement

Project maintainers may remove, edit, or reject comments, issues, commits, or pull requests that violate this code. Repeated or serious violations may result in a temporary or permanent ban from project spaces.

Report conduct concerns privately to the repository maintainers. Do not include sensitive personal information in a public issue.
