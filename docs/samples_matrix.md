# Sample Coverage Matrix

This document tracks the ANGLE sample capabilities represented in angle-dotnet. A checked entry means that the repository contains a managed or native demonstration for the capability.

| Capability | Example | Status |
| --- | --- | --- |
| Basic GLES rendering | Triangle, vertex shader | Implemented |
| Offscreen readback | Demo3 offscreen | Implemented |
| Texture sampling | 2D texture, multi-texture, cubemap | Implemented |
| Mipmap and filtering | Mipmap 2D | Implemented |
| Depth and stencil | Stencil operations | Implemented |
| Instanced rendering | Simple instancing | Implemented |
| Multiple render targets | Multiple draw buffers | Implemented |
| Multiview | OVR multiview sample | Implemented where supported |
| Post-sub-buffer updates | Post-sub-buffer sample | Implemented where supported |
| Multiple EGL surfaces and contexts | ANGLE multi-window samples | Planned |
| Shared contexts and cross-thread synchronization | ANGLE multiple-context samples | Planned |
| GLES1 fixed-function samples | ANGLE GLES1 samples | Planned |

The matrix describes project scope, not a promise that every ANGLE upstream sample is supported.
